# 天翊班务簿 · 42人学号版

古典书卷风：纸色、墨绿、朱砂，宋体标题。只使用 01—42 号学号，不预置学生姓名，可调整人数及学号。

## 进入页面

- 用户名：**天翊**（默认显示）
- 初始密码：**1024**
- 进入后点“修改密码”，填写当前密码、新密码和确认密码。
- 点“锁定”返回访问锁页面；重新打开网页也需要输入密码。

这是**本机访问锁**，密码修改仅对当前设备、当前浏览器、当前网址生效。密码校验值保存在本机；记录本身没有加密，静态源码也不是受保护的服务器资源。它不构成服务器身份认证，不能作为敏感资料的访问安全边界。清除浏览器数据会清除记录和改过的密码，新设备默认仍用 1024。所有设备共享一套可修改密码，需要另做后台验证。

备份文件不包含访问密码，恢复备份不会更改本机密码。

## 日常登记和历史状态

- 作业：点击学号登记已交，再点撤回。
- 红领巾：点击学号登记已带，再点撤回。
- 值日：先选当天值日生，再登记完成情况。
- 随机小助手：当日优先抽取未当选的同学。
- 每次登记自动保存到当前浏览器；“保存当天状态”也能保存全部待完成的空白记录。
- “历史记录”按日期倒序列出各项完成数量及当日小助手，点“查看当天”查看每个学号的具体状态。
- 每个日期保留自己的学号名单；调整所选日期的学号会更新该日和后续新记录的默认名单，其他已保存日期保持原样。
- 历史日期允许补记、更正；页面会显示正在查看的日期。保存的是该日期最新状态，不是逐次操作的审计日志。
- 没有按天自动删除记录。最多支持 5000 个日期；浏览器容量也有限，建议定期保存备份。

## 保存到电脑或手机

1. 点顶部“本机备份”，再点“保存备份到本机”。
2. 浏览器下载 `tianyi-class-records-日期.json`，包含全部已记录日期、每位同学的状态、各日期名单和值日安排。
3. Windows 在下载提示中保存到指定文件夹；手机可将下载文件存入“文件”应用。
4. 换设备、清理浏览器或搬到新网址后，在同一工具里点“从备份文件恢复”，选择 JSON 文件。
5. 恢复前会确认：其他日期会合并保留，同日期以备份为准；默认学号也按备份恢复。恢复误操作可立即点“撤销”。

请保留 JSON 文件，不要直接修改内容。建议每周下载一份；清理浏览器或更换网址前先备份。网页不能在不经浏览器允许的情况下静默写入任意电脑文件夹，因此本机文件备份需要主动点击保存。文件恢复上限 10 MB。

## Windows IE11 与手机

- 页面脚本使用 ES5 写法，不依赖箭头函数、Map、Set、Promise、现代数组方法或在线脚本库。
- IE11 使用专用布局回退、固定色值、兼容弹窗及 `msSaveOrOpenBlob` 文件保存方式。
- IE11 不支持原生日期控件时，输入 `YYYY-MM-DD` 格式日期，页面会校验日期。
- 手机采用较大的触控按钮、纵向历史卡片、全宽备份按钮，输入框字号不小于 16px。
- 已验证核心状态和文件恢复逻辑，并在移除现代 JavaScript API 的模拟环境中验证主要流程；**没有进行真实 IE11 或手机浏览器实机测试**。IE10及更早版本不在兼容目标内。
- 学校浏览器策略、下载限制或浏览器内嵌环境可能影响文件保存，需要在老师实际设备上确认。Render 网站连接本身也需在该设备上验证。

实现依据：[微软 msSaveOrOpenBlob 文档](https://learn.microsoft.com/en-us/previous-versions/hh772332(v=vs.85))、[FileReader 文档](https://developer.mozilla.org/en-US/docs/Web/API/FileReader)。

## 发布到 GitHub + Render

1. GitHub 新建独立仓库，例如 `classroom-helper`。
2. 解压发布包，将 **public 文件夹、styles.css、build.mjs、render.yaml、README.md** 上传到仓库根目录。不要直接上传 ZIP，不要套一层目录。原来的数学商店项目保持原样。
3. Render 点击 **New → Static Site**，关联此 GitHub 仓库。
4. 填写下表并创建：

| 设置 | 内容 |
| --- | --- |
| Name | `classroom-helper-student-numbers`，重名可自定 |
| Branch | 上传所在分支，通常 `main` |
| Root Directory | 留空 |
| Build Command | `node build.mjs` |
| Publish Directory | `public` |

也可以 **New → Blueprint**，读取仓库根目录 `render.yaml`。发布成功后使用 Render 返回的 `https://…onrender.com` 链接。

`styles.css` 是样式源文件，构建时生成不依赖 CSS 变量的 `public/style.css`。`public/app.js` 包含业务逻辑，`public/access.js` 包含本机访问锁。没有需要安装的第三方依赖。

部署参考：[Render Static Sites](https://render.com/docs/static-sites)、[Render Blueprint](https://render.com/docs/blueprint-spec)。
